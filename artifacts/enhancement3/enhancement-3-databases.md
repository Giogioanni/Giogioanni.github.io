Enhancing this artifact so far has taught me (I have said this previously but even more now) how quick a working program can become so difficult to reproduce without professional structure and tooling. Overall, the artifact is improved not only in features but also in professionalism: it is now more portable, testable, and aligned with expectations for production-quality software.
