## Brief description of the artifact (what it is and when it was created)
My Appointment Service artifact is a small Java-based scheduling component I built around an Appointment domain model and an AppointmentService class. The project overall validates appointment data, stores appointments in memory by ID, and includes unit tests that verify expected behaviors such as rejecting invalid inputs and preventing duplicate IDs. I originally created this artifact as part of CS 320 and selected it for this class CS 499 because it gives me a clean starting point for demonstrating my professional software engineering improvements through refactoring, validation, and test expansion.
